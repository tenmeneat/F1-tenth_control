치명그립 초과 (코너 진입 과속)

최대 |a_lat| = 18.1 m/s² (목표 그립 5.0의 3.6배). 전체의 31%가 그립 초과. 조향 포화까지는 안 갔으나 그립 한계 초과.

참고조향 게인/언더스티어 회귀 신뢰 불가

자전거모델 회귀가 비물리적 해로 수렴했다(A=0.13, K_us=+0.0139). 코너가 하나뿐이거나 조향 포화 구간이 많아 L·κ와 a_lat이 공선성을 띤 경우다. 게인/언더스티어 판정은 이 bag으로 할 수 없다 — 여러 코너를 포화 없이 도는 주행으로 재측정할 것.

참고IMU 자이로 = deg/s 확인

자이로 z 최대 220 (deg/s 스케일). IMU_ANGULAR_SCALE(π/180) 보정 전제. 언더스티어 시 요레이트 카운터스티어가 조향을 더 밀어 포화를 앞당길 수 있으니 use_imu:=false A/B 권장.

권장 다음 셰이크다운

ros2 launch f1tenth_control control_real.launch.py \
    max_lateral_accel:=5 \
    min_speed:=1.5

＋ 코드 안전망 권장: 측정 a_lat이 그립 초과하거나 조향이 ±0.41에 포화되면 target_speed를 하드컷(스핀/limit-cycle 차단), recovery_lat_error 1.0→0.5.
