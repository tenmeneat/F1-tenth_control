참고조향 게인/언더스티어 회귀 신뢰 불가

자전거모델 회귀가 비물리적 해로 수렴했다(A=-0.99, K_us=+0.3123). 코너가 하나뿐이거나 조향 포화 구간이 많아 L·κ와 a_lat이 공선성을 띤 경우다. 게인/언더스티어 판정은 이 bag으로 할 수 없다 — 여러 코너를 포화 없이 도는 주행으로 재측정할 것.

참고IMU 자이로 = deg/s 확인

자이로 z 최대 89 (deg/s 스케일). IMU_ANGULAR_SCALE(π/180) 보정 전제. 언더스티어 시 요레이트 카운터스티어가 조향을 더 밀어 포화를 앞당길 수 있으니 use_imu:=false A/B 권장.

양호그립 마진 양호

최대 |a_lat| = 2.4 m/s² < 목표 5.0. 코너 그립 마진 확보.
