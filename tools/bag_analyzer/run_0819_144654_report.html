치명그립 초과 (코너 진입 과속)

최대 |a_lat| = 53.1 m/s² (목표 그립 5.0의 10.6배). 전체의 37%가 그립 초과. 선회반경이 최소반경(0.76m)에 닿는 샘플 13개 = 실제 풀락 스핀.

주의감속 권한 약함

그립 붕괴 이전 최저 종가속도 -2.18 m/s². 감속이 약해 코너 사전감속이 부족할 수 있음.

참고조향 기하 게인 정상 (A=0.78)

자전거모델 회귀 A=0.78(정상 1.0), 중립 오프셋 -0.0059 rad. **서보 게인은 원인이 아니다.** 요레이트 추종률이 낮은 건 언더스티어 그래디언트 K_us=+0.0121 rad/(m/s²) 때문 — 타이어·노면 물성이라 서보로 못 고친다. a_lat 5.0에서 추가로 먹는 조향 +0.061 rad(한계 0.41의 15%). 대응은 ① 이 노면에서 LUT 재보정(lut_calibration.launch.py) ② max_lateral_accel을 실측 그립 이내로.

참고조향 포화 한계 속도

K_us=0.0121이면 κ=0.7(R=1.43m) 코너에서 필요 조향이 ±0.41에 닿는 속도가 **4.59 m/s**. 그립 한계 √(그립/κ)=2.67 m/s와 비교해 낮은 쪽이 실제 구속조건이다.

참고IMU 자이로 = deg/s 확인

자이로 z 최대 549 (deg/s 스케일). IMU_ANGULAR_SCALE(π/180) 보정 전제. 언더스티어 시 요레이트 카운터스티어가 조향을 더 밀어 포화를 앞당길 수 있으니 use_imu:=false A/B 권장.

권장 다음 셰이크다운

ros2 launch f1tenth_control control_real.launch.py \
    max_speed:=3 \
    max_lateral_accel:=5 \
    min_speed:=1.5

＋ 코드 안전망 권장: 측정 a_lat이 그립 초과하거나 조향이 ±0.41에 포화되면 target_speed를 하드컷(스핀/limit-cycle 차단), recovery_lat_error 1.0→0.5.
