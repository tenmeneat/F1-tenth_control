# odom / SLAM / MCL 진단 도구 (2026-07-28)

실차 odom·SLAM·MCL 문제를 **추측 없이 숫자로** 가르기 위해 만든 도구 모음.
전부 관찰 전용(`/drive` 미발행)이라 주행 중 켜도 제어에 영향이 없다.

## 왜 이게 필요했나

07-28 "SLAM 맵이 깨진다 / 주행 중 포즈가 튄다"를 쫓다가, 원인 후보가
**odom 헤딩 · odom 거리 · 자이로 스케일 · 라이다 기울기 · slam_toolbox · MCL**
여섯 곳에 흩어져 있었다. 감으로 하나씩 건드리면 서로를 가려서 영원히 못 잡는다.
그래서 **각 축을 독립적으로 측정하는 도구**를 만들어 하나씩 배제했다.

## 계층 1 — odom 자체 검증 (기준자가 필요 없다)

| 도구 | 재는 것 | 기준자 |
|---|---|---|
| `gyro_scale_loop.py <bag>` | 자이로 스케일 | **닫힌 루프 = 정확히 360°** (기하학) |
| `lidar_odom_calib.py` + `lidar_fit.py` | 거리 스케일(`speed_to_erpm_gain`) | **라이다 = 절대 거리계** |
| `odom_yaw_diag.py` → `turngain.py` | odom 요레이트 vs IMU 실측 | IMU |
| `tilt_check.py <bag>` | 라이다 하향 기울기 | `h/tan(α)` 기하 |

**핵심 아이디어는 "외부 기준자를 공짜로 얻는 것"이다.** 닫힌 루프의 360°와
라이다의 mm 거리는 둘 다 캘리브레이션 대상과 완전히 독립이라 줄자가 필요 없다.

## 계층 2 — SLAM 오프라인 재현 (차가 필요 없다)

```bash
python3 filter_bag.py ~/rosbag2_... /tmp/bag_nomap    # map->odom 제거
bash replay_slam.sh base                              # 베이스라인
bash replay_slam.sh avp002 angle_variance_penalty:=0.02
python3 metric.py /tmp/slamrun/base /tmp/slamrun/avp002       # map->odom 표류
python3 map_quality.py /tmp/slamrun/base /tmp/slamrun/avp002  # 실제 맵
```

bag 하나만 있으면 파라미터를 몇 번이든 스윕할 수 있다. 트랙에 다시 나갈 필요 없음.

## 계층 3 — MCL 포즈 붕괴

| 도구 | 재는 것 |
|---|---|
| `pose_break.py <bag>` | 물리적으로 불가능한 `/pf/pose/odom` 점프 + 그때의 스캔 품질 |

## ⚠️ 이 도구들을 쓰다 실제로 틀렸던 것들 (같은 실수 반복 방지)

측정 자체가 조용히 거짓말한 사례들이다. 전부 07-28 하루에 겪었다.

1. **"최대 관측 거리가 10 m니까 바닥에 안 막힌다"** — 최대치는 빔이 *뚫을 수 있다*는
   뜻이지 *항상 뚫는다*는 뜻이 아니다. 간헐적 바닥 반사는 최대치를 안 바꾼다.
2. **전체 평균으로 보면 충돌 구간이 섞인다** — "전체 빔의 10%가 유령 반사"가
   실은 마지막 7초 충돌 구간이었다(0~45초는 0.0%). **시간축으로 나눠 볼 것.**
3. **"스캔의 30% 이상 오염" 같은 스캔 단위 임계는 소수 빔 특징을 놓친다** —
   바퀴 2개는 1081빔 중 몇 개뿐이라 1% 미만 버킷에 묻힌다.
4. **주행 구간만 필터링하면 표본이 트랙 일부에 몰린다** — 150스캔만 골라
   "왼쪽이 막혔다"는 잘못된 결론이 나왔다(전체로 보면 고정 가림 0/1081).
5. **끝점 2개만 쓰는 계산은 못 믿는다** — 라이다 거리 보정 9구간 중 7구간이
   벽 기울기 때문에 +17%/-4% 쓰레기값을 냈다. **전 구간 회귀 + R² 게이트** 필수.
6. **프로세스 잔재가 측정을 오염시킨다** — `kill $!` 가 `ros2 run` 래퍼만 죽여
   slam_toolbox 인스턴스가 누적됐고, 샘플 수가 2661→5229→7843 으로 늘었다.
7. **zsh 는 단어 분할을 안 한다** — 다중 ros2 파라미터가 한 인자로 뭉쳐
   `InvalidParameterTypeException` 으로 노드가 죽는데, tfbag 은 그대로 생겨서
   조용히 오독하게 된다. 스윕 스크립트는 **bash 로, 로그 검사와 함께** 돌릴 것.
8. **A/B 전에 반드시 같은 설정 3회로 산포를 재라** — 산포를 모르면 파라미터
   효과인지 노이즈인지 구분이 안 된다.
